# Matrix Mind Puzzle

Build a polished Telegram Mini App for the user's IQTestPro-style project, branded 'Essence IQ' (Uzbek-first). IMPORTANT: The core IQ test questions must be visual non-verbal reasoning puzzles like Raven's Progressive Matrices, NOT general-knowledge multiple-choice questions. Create original shape-matrix puzzles rendered with SVG/CSS: 3x3 grids with the bottom-right cell missing, using circles, triangles, pentagons, hexagons, squares; vary counts, rotation, fill, size, and position; four visual answer choices. Include clear pattern rules (row/column progression), randomize question selection without duplicates within a test, 20-question test, no strict timer by default, immediate answer feedback/explanations, final score and result summary. Add Uzbek/Russian/English language toggle, dark/light mode, responsive mobile-first design, Telegram WebApp SDK integration (safe fallback in browser), home screen buttons 'To‘liq IQ testni boshlash', 'Do‘st bilan battle', 'Sertifikatni tiklash', ranking section, and result certificate modal with download/share controls. Use original visual assets created in SVG, no external paid media service. Do not claim this gives a clinically valid IQ score; label result as practice estimate. Build a functional MVP with local demo state first, and structure code so a backend can be connected later. Design should closely match the supplied reference: dark navy background, purple-to-magenta gradient rounded buttons, light puzzle tiles with navy shapes, clean premium UI. Make sure answer choice tiles display the actual shapes, not letters/text.
